# Партнёрский режим подтверждений

Реализован в admin_bot/partner_confirmation.py как отдельный роутер
личного чата перед административным роутером.

Администратор: «Создать кабинет для подтверждения привилегий партнёров»
→ выбор партнёра (по 10 на странице) → код 8–64 символа.
Сотрудник: «Режим подтверждения привилегий для ПАРТНЁРОВ»
→ код → «Подтвердить привилегию» → номер участницы → услуга → подтверждение.

Требуется WEB с миграцией 20261026_0056 и API /api/v1/partner-confirmation.
Используются прежние WEB_API_BASE_URL, BOT_SERVICE_TOKEN,
TELEGRAM_ADMIN_API_TOKEN и TELEGRAM_ADMIN_IDS. Новых секретов нет.
Коды не сохраняются в FSM и удаляются из чата по возможности.
Авторизацию, подписку, ограничения попыток, повторные покупки и защиту
от дублей проверяет WEB. История и статистика общие с приложением.

Сначала обновить WEB и применить миграцию, затем перезапустить
bloomclub-admin-bot.service. На сервере с расходящейся историей Git
сохранить локальную ветку и переносить только нужные файлы; не затирать
.env, .venv, data и самостоятельное приложение telegram-mini-app.
