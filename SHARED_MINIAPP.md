# Единое приложение Bloom Club

Новая кнопка бота «Открыть в Telegram» открывает `BROWSER_APP_PUBLIC_URL`
как Telegram Web App. Кнопка получения кода для сайта остаётся.
В обоих случаях используется актуальная сборка `browser-mobile-app` из bloom_WEB,
один API и одна база. Старый `telegram-mini-app` этого репозитория не требуется
собирать, переносить или синхронизировать для этого способа запуска.

## Перед включением

1. Обновить WEB backend с общим BrowserIdentityResolver для Telegram-входа.
2. Убедиться, что `TELEGRAM_BOT_TOKEN` на WEB backend принадлежит именно боту,
   из которого открывается Mini App. Не публиковать токен и не передавать в браузер.
3. В окружении бота оставить `BROWSER_APP_PUBLIC_URL=https://app.bloomclub.ru`.
4. Обновить и перезапустить существующий admin_bot. Не запускать второй polling
   процесс с тем же токеном. Dockerfile корня запускает старое приложение,
   а не admin_bot: для этой задачи его разворачивать не нужно.
5. Отправить боту `/start` в личном диалоге и открыть новую кнопку.
   Опционально в BotFather настроить Menu Button на тот же HTTPS URL.

## Проверка на реальном Telegram

- Войти на сайте кодом от этого бота; запомнить номер участницы и подписку.
- Открыть Mini App: номер, срок подписки, коды, экономия должны совпасть.
- Проверить фото, загрузку чека, переходы и нижнюю панель на Android и iOS.
- Изменить категорию/партнёра в админке; обновить обе версии и сверить данные.
- Проверить возврат после закрытия, истечения сессии и смены Telegram-аккаунта.

Аккаунт сайта, созданный через VK или другой Telegram-профиль, нельзя
автоматически объединять по имени. Для него нужна подтверждённая привязка.

Оплату внутри Telegram проверять отдельно до публичного запуска:
для цифровых товаров/услуг Telegram требует Stars. Не считать существующую
оплату Т-Банком автоматически разрешённой внутри Mini App; классификацию
клубной подписки и допустимый сценарий нужно согласовать.

Эти изменения не настраивают BotFather и не меняют работающий сервер автоматически.
